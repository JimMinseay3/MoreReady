# MoreReady 桌面与网页应用

MoreReady 是基于 Electron 的本地项目与任务管理应用。v0.2.0 从悬浮组件重构为完整桌面工作区，现有项目、任务、依赖关系和主题设置自动迁移。

[下载 Windows 安装版](https://github.com/JimMinseay3/release/releases/latest) · [构建与发布记录](https://github.com/JimMinseay3/MoreReady/actions)

安装版支持 Windows 10/11 x64。下载 `MoreReady-Setup-版本号-x64.exe` 后安装；本版本尚未配置 Windows 代码签名证书。

## 发行与更新

安装版在“关于”中检查更新，发现新版本后点击下载，下载完成后点击“重启安装”。下载和安装均由用户发起。更新源为本仓库的 GitHub Releases，构建时自动生成 `app-update.yml`，发行版同时提供安装包、`.blockmap`、`latest.yml` 和 SHA-256 校验清单。网页预览和源码运行模式显示发行版下载入口。

本地构建安装包：

```powershell
npm ci
npm run dist:win
```

产物位于 `release/`。打包仅包含应用代码、图片资源和运行依赖，不包含本地项目备份、AI 配置、密钥或测试截图；安装与更新沿用 `%APPDATA%\\moreready-widget` 数据目录。

后续发布先更新 `package.json` 与锁文件中的版本，再更新 `RELEASE_NOTES.md`，提交后推送对应的 `v版本号` 标签。GitHub Actions 会先运行验证、构建 Windows 安装包，再上传全部附件并公开 Release；未带标签的 main 推送只运行验证。手动运行工作流可构建并保存安装包附件，不会自动公开发行版。

```powershell
npm version patch
git push origin main
git push origin --tags
```

发布标签必须与 `package.json` 版本一致。GitHub Actions 使用仓库提供的临时令牌发布，不需要在代码中填写个人令牌。已经公开的版本不会被发布脚本覆盖，修复后需提高版本号。

## 启动

```powershell
npm install
npm start
```

已有依赖时直接运行 `npm start`。启动器会清理 `ELECTRON_RUN_AS_NODE`，确保 Electron 以桌面应用模式运行。重复启动会唤回已有窗口。

## 网页预览

```powershell
npm run web
```

在浏览器中打开 http://127.0.0.1:5173/，也可在 Codex 的浏览器预览面板中打开这个地址。`npm run dev:web` 是相同入口。页面、任务画布和主题与 Electron 共用 `src/renderer/`，后续修改会同时用于桌面版和网页版。

预览服务仅监听本机。修改 CSS 后即时更新样式并保留正在编辑的内容；修改页面或脚本后自动刷新，若任务或项目编辑器正在打开，则等待保存或取消后刷新。停止服务用 Ctrl+C。端口冲突时可运行 `npm run web -- --port 5174`，日常使用建议保持同一地址。

网页支持项目、任务、依赖连线、子任务、标签、概览布局、筛选与主题。窗口控制在网页预览中显示为禁用，置顶、托盘和打开本机数据目录仅在 Electron 中显示。网页数据保存在当前浏览器、当前网站地址下，刷新或重启服务后保留；不同浏览器、端口或桌面版的数据相互独立。可用设置中的 JSON 导出/导入在两端转移数据，导入会覆盖目标端当前内容。清理网站数据或使用隐私窗口会影响保存，请定期导出备份。当前不提供账号或云同步。

## 桌面布局

工作区按提供的 Notion 参考图统一了中性色、紧凑分组侧栏、页面大标题与留白、淡色看板列和轻边框卡片。侧栏只展示工作空间和工具设置导航；搜索使用看板搜索框或快捷键，Miss.MR 使用右下角入口或快捷键。看板工具栏及每列底部都可以打开新建任务。晨光使用白色画布，夜幕使用中性深灰，主要操作按钮采用蓝色；强调色继续用于标签、图表和任务进度。

- 主窗口默认 1440 × 900，屏幕空间不足时自适应；支持自由调整大小、最小化、最大化，并记住窗口位置与尺寸。
- 左侧导航贯通整个窗口高度，右侧工作区顶部展示页面标题与标签页。侧栏打开的页面会加入标签栏，重复打开切回已有标签；加号菜单可选择页面，支持关闭标签、方向键切换与横向滚动。标签页列表随工作区保存；切换或关闭当前标签会保护未保存的任务、项目和模型配置。关闭最后一个页面后返回今日概览。
- 右侧提供应用的最小化、最大化/还原和关闭按钮，桌面版使用真实窗口操作；网页预览保留按钮并显示禁用状态。普通页面的小标题行已并入标签栏，正文保留大标题。
- 固定左侧导航：概览、日历、项目、看板、统计、回收站、扩展、关于、设置。扩展入口提供自定义 AI 服务配置。
- 项目工作区使用约 288px 的项目列表和占据剩余空间的任务画布；切换页面或项目不会改变窗口尺寸。
- 项目列表顶部并排提供“新建分组”和“新建项目”，下方是搜索栏与同排的项目状态、列表视图和画布详细/简洁模式。新建项目直接替换右侧画布，保留左侧项目列表，保存或取消后恢复画布；从任务表单中新建项目时会保留任务草稿并返回任务表单。
- 项目列表标题栏高度为 56px；任务画布取消独立标题行，从应用标签栏下方铺满剩余区域。项目导航中移除 AI 建议入口，助手工具仍可在 Miss.MR 的菜单中使用。
- 点击任务正文打开与画布并排的右侧详情栏；画布自动腾出空间，仍可操作。选中任务会高亮前置与后续依赖链，无关任务淡化。任务详情从应用顶栏下方铺满右侧整列，取消外侧留白和圆角卡片，有独立标题、表单滚动区域与固定操作区。详情支持优先级、提醒、项目显示、日期、标签、子任务、备注与删除；任务状态通过看板操作，依赖通过画布连线管理。
- 默认不置顶，关闭窗口直接退出；可在设置中选择置顶或关闭时收进托盘。托盘点击唤回窗口。

## 系统通知与自启动

在设置页的“通知与启动”中管理系统通知，侧栏不再提供单独入口。通知默认关闭，提供每日提醒时间（默认本地时间 09:00）和“发送测试”按钮。提醒汇总今日到期及已逾期的未完成任务，跳过已归档项目、已完成任务和回收站内容；每天最多一次。错过提醒时间后，应用再次打开或电脑恢复时补发当天提醒。当天发送记录单独保存，刷新或重启后不会重复发送。发送失败不计为成功，间隔至少 15 分钟再尝试。

Windows 桌面版通过 [Electron 的系统通知接口](https://www.electronjs.org/docs/latest/tutorial/notifications)发送通知，在应用运行或托盘常驻时检查任务；退出应用后暂停。点击通知打开相关任务，当前有编辑草稿时先提示处理草稿。Windows 的勿扰模式或系统通知权限可能影响横幅显示，可用测试按钮确认，并查看系统通知中心。网页版使用浏览器通知，需要允许网站的通知权限并保持页面打开；多标签页共享当天发送记录。点击测试不会开启每日提醒。

“开机自启动”默认关闭，在 Windows 桌面版中开启后会在登录电脑时自动打开 MoreReady。开关读取系统实际状态，关闭会移除当前应用的自启动项；网页版显示此选项及桌面版可用提示。桌面开发版同时注册 Electron 路径和项目目录参数，保持项目目录位置不变以便自启动正常运行。通知偏好保存在本机的 `system-settings.json`，当天提醒记录为 `reminder-state.json`；网页对应设置保存在当前网站的浏览器存储中。这些系统设置独立于项目备份，导入备份不会开启通知或修改系统自启动。

日历工具栏左侧提供“简约 / 详细”分段切换，并保存视图选择。简约模式显示任务圆点与数量；详细模式在日期格内显示任务标题和一行备注，没有备注时显示项目名，每天预览两项，更多任务可点击“还有 N 项”查看。单击日期选中当天，双击日期打开右侧新建任务，截止日期默认填入所点日期，所属项目可选择；新建和编辑使用同一套表单。点击任务预览直接进入详情；切换模式保留当前月份、选中日期和正在编辑的任务草稿。任务编辑的“✦ 拆解”入口位于底部操作栏，与删除、取消、保存同行。

## 任务画布

依赖方向从左到右。节点左侧连接点接收前置任务，右侧连接点连接后续任务。左侧项目导航区提供详细/简洁视图，选择单独保存；详细模式显示全部子任务。卡片按每张内容测量宽高，长标题和子任务自动换行，连线端点和布局间距同步适配。

- 拖动右侧连接点到后续任务左侧连接点，或依次点击两点，可建立依赖关系。
- 连线箭头使用固定 8px 尺寸，不因选中时线条加粗而变大。
- 支持分支与汇合，跨层连线绕过中间节点；自依赖、重复连接和循环依赖会被拦截。
- 互不相连的任务组紧凑排布，避免所有独立起点排成一条长行。
- 拖动画布空白处平移，滚轮平移，Ctrl + 滚轮缩放；缩放、适应视图、100% 与添加任务悬浮在画布内部底部，适应视图会为工具条留出空间。
- 画布空白处右键「新建任务」，任务自动归入当前项目；空项目也可使用。
- 画布任务标题下方显示子任务；详情栏将子任务放在项目、日期、状态、优先级四个控件下方，按回车添加，支持完成和移除。子任务下方只读展示前置任务及其状态，连线变化时同步更新。
- 新标签使用内联输入，支持回车添加与取消。
- 按 Esc 取消连线或右键菜单；任务详情中按 Esc 取消编辑，Ctrl + Enter 保存。

## 项目分组

项目页通过顶部“新建分组”按钮就地输入分组名称，原“管理分组”区域已移除。既有无分组项目和新建时未指定分组的项目均显示在“默认分组”。项目卡片悬停或键盘聚焦时显示编辑、移动至分组、归档和删除按钮；也可拖动卡片到分组标题，或在项目详情中选择归属。分组支持折叠，归属与折叠状态自动保存并随 JSON 备份迁移，修改分组不会删除项目和任务。

## 看板与甘特时间线

“任务看板”右侧提供“甘特时间线”，两种视图共用项目筛选、居中搜索和新建任务入口，视图选择会保存。看板分页与展示使用相同的状态桶、搜索结果和项目范围，筛选后返回第一页，边界按钮禁用。

甘特时间线横轴为日期，每行一项任务，按现有截止日期显示单日标记；未排期任务单独显示，不推断开始日期或工期。支持前后四周、回到今天、点击任务日期定位，点击标题或标记打开原任务详情。日期表头和任务名称固定，表格可横向与纵向滚动。

扩展页的模型列表使用本地品牌 SVG，已连接模型可显示 Claude、DeepSeek 或 Qwen 图标；已连接区域与模型列表间距收紧。图标源自 Lobe Icons，来源版本与 MIT 许可保存在 `src/renderer/icons/providers/`。

已有任务的“所属项目”在详情中只读显示，保存其他字段会保留项目归属与前置依赖。新建任务仍可选择项目。

## AI 扩展

“扩展”采用居中的双圆角区域：左栏顶部切换“插件 / 模型”，“模型”页按“已连接”和“模型列表”分区，右侧显示“模型设置”，填写 API 地址、模型名称和密钥。“已连接”列出当前保存的模型，并区分已配置与待连接状态；保存或移除配置后同步更新。插件页可查看内置 Miss.MR 并打开助手或前往模型设置。切换页签不会丢失正在填写的配置。提供 OpenAI、DeepSeek、阿里云百炼、硅基流动、Ollama 与自定义 API；常用服务自动填入地址预设，每项均可自行修改，模型名称按服务提供方填写。表单中附有官方接口文档链接。保存后点击“测试连接”，已保存的提供商选择会在重新打开时恢复。

地址可填服务基础路径（例如提供商给出的 `/v1` 地址），也可填写完整 `/chat/completions` 地址。服务必须兼容 [OpenAI Chat Completions 格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。远程服务要求 HTTPS，本机服务允许 HTTP。切换提供商保留各自未保存的地址与模型草稿，未保存密钥不会被带到其他提供商；更换接口地址时必须重新填写密钥。本地 Ollama 可不填密钥。

右下角的圆形按钮展开或收起 Miss.MR。助手使用参考图中的中性色、紧凑图标栏、靠左欢迎区和底部圆角输入框，支持放大与恢复。欢迎入口为“总结此页面”“翻译此页面”“深度剖析”“创建任务跟踪器”：前三项将当前可见页面文字放入输入框，由用户点击发送后才发给模型；已有输入会保留，配置表单的密钥不被复制。任务跟踪入口打开项目规划表单，生成前可选择项目与补充目标。输入区支持回车发送、Shift+回车换行、停止请求和新建对话。收起后保留当前对话与输入。普通对话只发送聊天消息；项目数据由下述工作方式明确选择后发送。对话与方案保存在当前页面内存，刷新后清空。

浮动栏目移除了横排工作方式按钮。“规划任务”“拆解任务”“梳理依赖”“项目建议”和模型配置位于右上角“更多操作”及输入框加号的菜单中。选择项目或任务并补充目标，点击“生成方案”后向已配置的真实服务发送该项目的任务、备注、子任务及依赖。左侧项目导航区可直接打开 AI 建议，未完成任务的编辑栏可直接打开拆解。正在编辑的目标任务采用当前草稿；生成不会修改数据。

方案以任务、子任务、依赖和风险建议卡片展示。勾选后点击“应用所选”，才新增任务、子任务或依赖。任务拆解应用到编辑草稿，需要点击任务的“保存”按钮；取消编辑会放弃这些子任务。可撤销未被后续修改的本次应用。方案不支持删除、跨项目移动或自动完成任务。循环、重复、缺失依赖及过时的项目/草稿会被拦截；只选后续新任务时须同时选中它的新前置任务。“项目建议”始终只读。

OpenAI 和 DeepSeek 配置使用 JSON 输出模式；其他兼容服务使用 JSON 格式提示并执行相同校验。已有预览进程可通过原对话接口生成并校验方案，保留进程内的密钥，无需为界面更新重启服务。请求失败或停止后保留补充目标，后续可重新生成。应用到项目的条目写入活动记录。

桌面版通过主进程请求 API，支持系统加密时将密钥加密保存到 `ai-config.json`；系统加密不可用时仅保留在进程内存。网页版通过本机预览服务请求 API，避免浏览器跨域限制；地址和模型存放在 `.local-ai/config.json`，密钥仅存在服务进程内存，重启服务后需要重新填写。项目备份不包含密钥。修改代码时，尚未保存的 AI 配置、未发送的输入以及进行中的请求会阻止自动刷新。

自动检查使用本地模拟服务验证请求格式、配置、快捷提问、对话与草稿保留、取消、报错及项目方案；真实服务需要填写有效配置后测试连接。

## 快捷键与鼠标

设置页新增“快捷键与鼠标”，点击操作对应的键盘或鼠标按钮后录入绑定，支持新建任务/项目、搜索、项目页、前后页面、保存、详细/简洁切换和 AI 展开/收起。鼠标侧键 4、5 默认对应前后页面，也可映射到其他操作；桌面版同时接收 Windows 的前进/后退应用事件。键盘需使用 Ctrl、Alt、⌘ 组合或 F1–F24。发生冲突时显示原绑定，“替换并保存”会清除冲突项；支持清除绑定、恢复默认并随项目备份保留映射。

映射在当前窗口内生效；桌面全局 Ctrl + Shift + Space 固定用于显示/隐藏窗口，不能在映射中占用。新建或页面切换快捷键会提醒先处理编辑草稿，保存快捷键只作用于任务/项目编辑器。看板右侧视图按钮点击即可在详细/简洁之间切换并保存。

## 其他页面

统计页在状态分布上方展示近 14 天的日历热力图，按已完成任务的截止日期归组；支持星期排列、每日数量、今天标记、日期提示、合计与颜色图例，配色随主题和强调色变化。汇总说明靠右对齐，颜色图例纵向排列。

强调色支持预设颜色和应用内自定义色板。点击“自定义”后拖动饱和度/明度色板、调整色相或输入 HEX 色值，实时预览全应用配色；点击“应用”保存，取消或离开页面恢复已保存颜色。支持键盘方向键调整、三位/六位 HEX、回车应用和 Esc 取消。

概览按卡片展示今天到期、正在进行、接下来、最近完成与项目进度；完成率居中显示。拖动卡片标题旁的手柄调整顺序，拖动右下角调整宽高，布局自动保存并支持恢复默认。看板提供搜索、项目筛选、排序以及右侧详细/简洁视图，详细模式显示完整子任务列表，简洁模式隐藏子任务；视图选择单独保存。任务状态由四列展示。项目卡片在悬停或聚焦时显示编辑、移动至分组、归档和删除按钮，归档可再次取消，删除移入回收站并保留还原能力。编辑按钮在最右侧打开项目详情，描述下方展示全部任务及状态和日期，归档操作移到卡片按钮；新建项目在右侧画布区域填写。日历、统计、回收站及导入/导出继续可用。MoreReady 主题包括晨光（白色浅色）与夜幕（中性深灰），主要操作使用蓝色；支持跟随系统与保留的其他主题。设置页按外观、快捷键、通知与启动、使用偏好和数据依次纵向排列，所有窗口尺寸均采用单列布局，提供即时配色预览、预设颜色与自定义色板入口。强调色应用于标签、图表、任务进度及关于页 Logo，强调色文字会计算对比度，状态色在浅深主题间保持相同含义。关于页仅保留四项：Logo、版本、检查更新、版权。安装版通过 GitHub Releases 检查、下载并安装新版本。

## 数据与迁移

内部应用标识仍为 `moreready-widget`，用于保留原有用户数据目录：

```text
%APPDATA%\moreready-widget\store.json
%APPDATA%\moreready-widget\window-state.json
```

项目数据使用 schema 6，新增分组数据并兼容旧项目。迁移仅调整组件模式的窗口默认设置，不重建任务、项目或依赖关系。首次迁移前，原数据会自动备份到同目录的 `store.before-desktop.json`。窗口状态单独存储，JSON 使用临时文件写入后替换。可从设置中导出备份或打开数据目录。

组件版本源码备份位于 `backups/widget-v0.1.0-before-desktop.zip`。

截图输出到 `shots/`。

工作流检查使用独立项目与模拟模型，覆盖依赖校验、勾选应用、撤销、编辑草稿保留、过时方案、错误/取消、绑定冲突和重新打开后保留。桌面检查验证实际 IPC 与 Windows 应用侧键事件；未模拟物理鼠标驱动。保存真实 AI 配置后，可单独运行 `node tools/verify-live-ai.js`，向该服务发送虚构的连接验证示例，生成两项任务并校验依赖，结果记录在 `shots/live-ai-verification.json`，不修改工作区项目。

`verify:system` 使用临时项目数据和独立的 Windows 测试应用标识，检查真实的通知显示回调及自启动项写入/移除，结束时清理测试启动项和快捷方式；不改动正式应用的自启动设置。浏览器权限、重复提醒与失败状态使用隔离浏览器及模拟通知验证。系统通知横幅的实际位置和显示时间由系统控制。
